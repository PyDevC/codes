# Barebone C++

Here I am not going to use any build system but will explore C++ using only 
compiler flags.

Let's see old school way of doing things and see If what how can I make my life
easy with them and also try Modern C++ with several features for performance
boosting as well as smaller binaries.

```bash
clang++ <filename>.cpp -o barebone
```

> Always keep the name of your binary `barebone`

you can even compile multiple files at once if they are compatible and does 
have competing functions.
